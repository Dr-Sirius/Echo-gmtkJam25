# ECH//O
Echo is my submission to the GMTK Jam 2025. Echo attempts to fit the jams theme of "Loop" by trapping your character in a time loop. 
You as the player help yourself with your time looped copies to complete a level. 
Echo aims to be a speed running puzzle solving platformer. 

## How does it play?
Each level you start with a maximum number of loops 
<img width="141" height="27" alt="Screenshot_20260908_235944" src="https://github.com/user-attachments/assets/98d95299-d2d3-45cd-a6ae-e326d52e7619" />

Your goal in the loop is to complete a portion of the level puzzle before your allotted loop time runs out <img width="149" height="24" alt="Screenshot_20260909_000023" src="https://github.com/user-attachments/assets/9b766c47-aa0f-49f1-9fb8-87eb6a455b30" />

Not all loops will always need to be used, varies by level.

If you complete the puzzle successfully, the elevator door will open to take you to the next level.

## What works and what doesn't
### Levels
Currently, there is only three levels implemented in the fracture section

- level_1_fracture
- level_2_watch_your_step
- level_3_order_of_operations
  
Level 1 is fully working and complete, having received its full art pass.

level 2 fully works, however needs to be tweaked in the platforming aspect and the art pass is not fully done

level 3 is neither fully working, nor has had an art pass. Level 3 is a remnant of the original jam submission version

### Saving
The save system is broken currently for admittedly mostly unknown reasons. Level loading may need to be rewritten, however, unknown at this point. 
The project has remain mostly untouched for the better part of a year and so is in need of dire changes.
